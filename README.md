# VoxPilot downloads

VoxPilot lets you talk to any app on your Windows PC. Hold one key, speak, and it types what you mean, or does it.

**Download:** open [the latest release](https://github.com/nivasthumma/voxpilot-releases/releases/latest) and run **VoxPilot-Setup.exe**. It needs Windows 10 or 11 and no admin rights.

Installed copies update themselves from this page. Each release lists the SHA-256 checksum of its installer.

This repository holds release files only.
